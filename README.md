Category Management System

Project Overview

The Category Management System is a web-based application developed using Java and Spring Boot. It provides a dashboard for managing categories.

Technologies Used

- Java 21
- Spring Boot
- Maven
- MySQL
- HTML
- CSS
- Bootstrap 5
- JavaScript

Requirements

- Java JDK 21
- Eclipse IDE
- MySQL Server
- MySQL Workbench
- Maven

Database Setup

1. Open MySQL Workbench.
2. Create a database named "category_management".
3. Configure the database connection in "application.properties".

How to Run

1. Clone or download this repository.
2. Import the project into Eclipse as a Maven project.
3. Configure the MySQL database.
4. Run the Spring Boot application.
5. Open the application in your browser.
